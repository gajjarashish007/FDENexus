About this interface

This is a static, frontend-only demo of the FDE Nexus platform console, built from the platform specification. It uses HTML, CSS, JavaScript and Bootstrap 5.

It brings together three real tools from this repository:

  • AI Infrastructure Validator (validator/): the unified portal for AWS validation, IAM, Service Quotas and self-service.
  • Pod Dashboard / EKSense (pod/): day-2 EKS operations and troubleshooting.
  • Atmos Workshop (workshop/): plan and deploy infrastructure with Atmos + Terraform.

Built with open-source tools:

Terraform, Atmos, Kubernetes/EKS, kubectl, YAML, GitHub, GitHub Actions, Argo CD (GitOps), Slack, AWS, Python/FastAPI and Bootstrap. See the Tech Stack page.

  • No backend. There are no APIs, databases, authentication or cloud calls.
  • Simulated actions. Buttons, filters, approvals, runs and downloads only update the screen using mock data.
  • No secrets or real data. All names, resources and numbers are fictional.
